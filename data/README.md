# data/

- `samples/`: هفت فریم نمونه از cam1. نام هر فایل، تاریخ و ساعت روی همان تصویر است.
  - نوامبر: جوجه‌ی یک‌روزه
  - دسامبر: مرغ ۳ تا ۵ هفته‌ای
- `raw/<camera>/<YYYY-MM-DD>/`: ویدیوهای خروجی DVR را اینجا بگذارید. پوشه‌ی تاریخ لازم است چون در نام فایل‌هایی مثل `05.45.00-05.50.00RO000.h264` فقط ساعت آمده.
- بقیه‌ی محتوای این پوشه را خود سامانه می‌سازد (`pews.sqlite`، `grids/`، `media/`) و در git ثبت نمی‌شود.
